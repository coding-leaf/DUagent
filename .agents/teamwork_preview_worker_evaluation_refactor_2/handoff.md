# Handoff Report - Refactoring Backend Evaluation Module

## 1. Observation
- In `backend/app/infrastructure/locks.py`, the original lock file had only `profile_lock`. We modified this file to append the `evaluation_lock` async context manager which checks if dialect name is `"sqlite"` to skip the named lock:
  ```python
  @asynccontextmanager
  async def evaluation_lock(db: AsyncSession, user_id: str, course_id: str):
      raw = f"evaluation_{user_id}_{course_id}"
      if db.bind.dialect.name == "sqlite":
          yield raw
          return
      lock_result = await db.execute(text("SELECT GET_LOCK(:name, 5)"), {"name": raw})
      if not lock_result.scalar():
          raise RuntimeError(f"GET_LOCK timeout: {raw}")
      try:
          yield raw
      finally:
          await db.execute(text("SELECT RELEASE_LOCK(:name)"), {"name": raw})
  ```
