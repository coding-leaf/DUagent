# 教材安全切片与版本化幂等入库改造 (PRD)

## 1. 目标与背景 (Goal & Background)

在高校课程教材入库任务（如 `863bee78bd9e46b5`）中，教材 PDF（如《C程序设计语言》）切片向量化因包含大量目录长连点（`..........`）及密集中文字符，导致超出 Embedding 模型的单条 Token 上限，触发服务商 400（`code: 20015: The parameter is invalid`）致命错误并导致入库失败。

本任务旨在重构 `agent_service_v2` 中的 RAG 教材切片预处理、分块机制与 Qdrant 写入流水线，实现：
1. 敏感格式防误伤清洗与 Token 感知自适应递归二次分块；
2. 章节路径结构化 Payload 注入与检索前缀增强；
3. Qdrant 蓝绿版本化幂等入库（严禁先删后写，写入校验通过后原子切换版本并异步清理旧数据）；
4. 向量空间物理隔离（不同模型/版本严格分离 Collection，严禁混存）。

## 2. 详细需求 (Requirements)

### 2.1 结构感知与防误伤清洗
- **差异化清洗规则**：必须区分目录区、正文段落、代码块与数学公式。严禁激进正则清除代码缩进、Markdown 语法标记、注释及数学公式符号。清洗主要针对目录页引导线（如连续 3 个以上的点、点阵符 `[\.·•]{3,}` 压缩为 `...`）及页面边角噪音。
- **章节层级 Payload 注入**：保留解析出的层级大纲信息（Breadcrumbs），作为结构化元数据（`chapter_path`、`headings`）写入 Payload，并在 Embedding 文本前缀注入精简章节上下文（例如 `[第1章 导言 > 1.2 变量与算术表达式]`）。
- **降级容错**：当 PDFParser 章节解析失败时，自动平滑降级至普通文本滑动窗口分块，不得抛出异常阻断入库。

### 2.2 Token 感知自适应递归切片
- **参数可配置化**：分块参数（如 `chunk_size`、`overlap`）支持通过配置/参数传入（默认提供稳健初值），切片时优先保留段落边界与代码块完整性。
- **取消静默字符截断**：严禁采用粗暴字符长度硬截断。改用 Token 计数与模型最大上下文检测；当单块内容超出模型安全 Token 上限时，触发**递归子切片（Recursive Sub-chunking）**继续拆分，确保所有内容均被完整覆盖且不超限。

### 2.3 Qdrant 蓝绿版本化幂等入库
- **明确三层标识语义**：
  - `course_id`：业务教学班级/权限隔离标识；
  - `catalog_id`：知识库教材目录与索引权威标识；
  - `material_id`：具体文件素材标识；
  - `ingestion_version`：新增切片批次版本戳（UUID 或毫秒级时间戳）。
- **零中断版本化切换（严禁先删后写）**：
  - 写入新版本切片并附带 `ingestion_version`，支持 16~32 块分批写入与重试；
  - 全量切片写入完成并通过数量与基础检索验证后，原子更新当前生效版本（Active Ingestion Version）；
  - 检索端通过 Filter 仅检索生效版本；切换完成后，异步删除淘汰旧版本数据点。入库中途失败不影响现有生效版本。
- **向量空间物理隔离**：
  - Collection 名称根据配置的 Embedding 模型与维度动态命名（或增加模型后缀，如 `course_knowledge_v1_1024` 与 `course_knowledge_bge_m3_1024`）；严禁不同模型或不同向量空间的向量混在同一个集合。

### 2.4 接口与契约兼容性
- 保持对外 `POST /agent/v2/knowledge/ingestions` 及 Backend `/api/v1/admin/course-catalogs/{id}/ingestions` 接口协议和入参完全兼容。
- 保证已有的 7 项全仓 CI 质量门禁通过。

## 3. 验收标准 (Acceptance Criteria)

- [x] **AC-1 (格式防误伤清洗)**：包含代码块（C/Python代码）、公式和目录长连点的教材文本，清洗后代码缩进与符号完整保留，目录长连点被正确压缩，不引发分词 Token 膨胀。
- [x] **AC-2 (递归安全切片)**：对任意长章节、超大目录页，分块流水线均能将所有 chunk 控制在模型安全 Token 窗口内（针对 512 或 8192 模型均不溢出），无静默丢弃，且大纲失败时自动降级。
- [x] **AC-3 (蓝绿版本写入与检索隔离)**：重新入库教材时，老数据在写入过程中依然可被正常检索；新版本写入并通过校验后才切换；旧数据在切换后被正确清理；重复触发具备幂等性。
- [x] **AC-4 (模型集合隔离)**：切换 Embedding 模型时自动采用对应隔离的 Qdrant Collection，不破坏已有集合。
- [x] **AC-5 (真实文件回归)**：任务 `863bee78bd9e46b5` 中的真实 PDF《C程序设计语言 (Brian W. Kernighan, Dennis M. Ritchie) ...pdf》入库流程能够完整执行成功，不再抛出 400 `code: 20015` 异常。
- [x] **AC-6 (质量门禁)**：`python -X utf8 check_all.py` 门禁全项 PASS。
