# EDUagent 本地联调测试指导

## 启动

推荐从项目根目录运行：

```bash
./start_all.sh
```

该脚本启动 MySQL、Qdrant、Agent Service v2（8002）、Backend（8001）和 Frontend。

单独启动 Agent Service：

```bash
cd agent_service_v2
./.venv/bin/uvicorn agent_service_v2.main:app --host 127.0.0.1 --port 8002
```

## 基础检查

```bash
curl -fsS http://127.0.0.1:8002/openapi.json >/dev/null
curl -fsS http://127.0.0.1:8001/health
```

Agent Service v2 不提供旧 `/agent/v1/health`；以 OpenAPI 可达性和对应业务 smoke/test 判断就绪。

## 关键链路

1. 上传课程资料到 Backend；Backend 调用 `/agent/v2/knowledge/ingestions`。
2. 生成并激活 KG；Backend 调用 `/agent/v2/knowledge/knowledge-graphs/generations`。
3. AI Chat 通过 Backend 代理 `/agent/v2/workbench/chat`。
4. 公共资源和题目通过 `/agent/v2/knowledge/*` 生成。
5. 学情评估通过 `/agent/v2/evaluation/*`。
6. 学习路径由 Backend 基于 active KG 与实时进度返回，不调用 Agent。

## 回归命令

```bash
cd frontend && npm run lint && npm run build
cd backend && ../.venv/bin/python -m pytest tests/test_retired_agent_v1_routes.py -q
cd agent_service_v2 && ./.venv/bin/pytest
```

联调失败时优先检查 `.run_logs/start_all/`，不得把密钥或 `.env` 内容打印到日志。
