# Docs Index

项目文档统一放在根目录 `docs/` 下，按用途分层：

- `00-overview/`：项目总览与需求原件
- `10-client-api/`：前端与 Backend 正式契约
- `20-agent-api/`：Backend 与 Agent Service 正式契约
- `30-dev-guide/`：开发导读与协作说明
- `90-review/`：一致性审查与结论
- `archive/`：历史归档，不作为当前开发依据

建议阅读顺序：

1. `00-overview/README.md`
2. `10-client-api/API_前端接口规范.md`
3. `20-agent-api/API_Agent内部接口规范.md`
4. `30-dev-guide/Agent-Service_开发导读.md`
5. `90-review/API一致性最终审查.md`

协作约定：

- 当前开发以 `docs/` 下的非归档文档为准。
- `archive/` 仅保留历史记录，不作为字段和接口真相源。
