# 设计文档：Agents.md 架构模式与代码生成规范扩展

**日期：** 2026-06-25
**状态：** 已批准
**目标文件：** `Agents.md`（根目录）

---

## 背景

当前 `Agents.md` 已有流程约束（修改前汇报、任务分级、Git 规范），但缺乏对代码写法本身的约束。
AI 在没有架构约束时容易出现：退化胖路由/胖组件、不用已有工具重造轮子、注释冗余、引入未声明依赖。

---

## 方案决策

- 约束防御目标：退化 + 生成质量 + 依赖引入，综合管控
- 执行粒度：小修免检，中等/大改提交前附结构化自检结果
- 描述方式：原则 + 典型反例（灵活，不强制具体数值硬编码）
- 覆盖范围：只写根目录 `Agents.md`，子项目 AGENTS.md 不动

---

## 新增内容

### 1. 架构模式规范 section

三个子项目各一块，格式：原则 + 典型反例。

**前端 React/SWR/MVVM**
- Page = 容器，不写业务逻辑和 fetch
- 数据获取统一走 SWR hook
- 组件只接收 props，不持有异步状态

**后端 FastAPI 分层**
- Router = 鉴权 + 参数校验 + 响应包装，不写 SQL
- 业务逻辑和 DB 操作下沉到 Service

**Agent Service 编排分层**
- `agents/` 负责编排，不直接调 LLM
- `tools/` 封装单一能力，不含流程判断
- `prompts/` 只存模板，不含调用逻辑

### 2. 代码生成规范 section

覆盖四类：文件/函数体积、注释风格、依赖引入、工具优先复用。

### 3. 任务分级补充

中等/大改提交前附 4 项结构化自检，小修免检。
