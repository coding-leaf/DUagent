# Learning Effects Summary UI Optimization Design Spec

## 1. Goal Description
The "Learning Effect Summary" (学习效果总结) card on the Student and Teacher dashboards currently displays AI-generated diagnostic summaries as a single raw text paragraph of about 500+ Chinese characters. This wall of text is difficult to scan, causes cognitive fatigue, and hides crucial action items.

This document specifies the design for parsing the raw natural language summaries client-side and rendering them into a modern two-column split dashboard layout. 
- **Student Dashboard**: Shows structured, color-coded diagnostic panels on the left, and an actionable vertical task checklist on the right.
- **Teacher Dashboard**: Shows a compact checklist version of the summary so teachers can quickly identify weak spots and action plans for individual students.
- **AI Chat & Prompts**: Keep receiving the raw string format from the backend to ensure natural language reasoning capability for downstream LLM prompts.

### 2.1 [NEW] [summaryParser.js](file:///home/yezisama/workspace/workflow/EDUagent/frontend/src/utils/summaryParser.js)
Create a helper utility to parse the structured text generated by the AI evaluation agent into a structured Javascript object.

```javascript
/**
 * Parses the raw evaluation summary text into structured sections.
 * Expected sections: 学习范围、当前掌握、学习行为、下一步建议.
 */
export function parseSummaryText(text) {
  if (!text) return null;

  const markers = [
    { key: 'scope', marker: '学习范围：' },
    { key: 'mastery', marker: '当前掌握：' },
    { key: 'behavior', marker: '学习行为：' },
    { key: 'suggestions', marker: '下一步建议：' }
  ];

  const found = markers
    .map(m => ({ ...m, index: text.indexOf(m.marker) }))
    .filter(m => m.index !== -1)
    .sort((a, b) => a.index - b.index);

  if (found.length === 0) {
    return { scope: text, mastery: '', behavior: '', suggestions: [] };
  }

  const result = {
    scope: '',
    mastery: '',
    behavior: '',
    suggestions: []
  };

  for (let i = 0; i < found.length; i++) {
    const current = found[i];
    const next = found[i + 1];
    const startPos = current.index + current.marker.length;
    const endPos = next ? next.index : text.length;
    const content = text.substring(startPos, endPos).trim();

    if (current.key === 'suggestions') {
      const itemRegex = /(?:\d+[\)\）\、\.])\s*/g;
      const parts = content.split(itemRegex);
      
      const items = [];
      let prefix = '';
      if (parts[0] && parts[0].trim()) {
        prefix = parts[0].trim();
      }
      
      for (let j = 1; j < parts.length; j++) {
        const itemContent = parts[j].trim();
        if (itemContent) {
          // Robust title extraction (split by comma, parentheses or semicolon)
          let title = '';
          let desc = itemContent;
          const splitIdx = itemContent.search(/[，（(,]/);
          
          if (splitIdx !== -1 && splitIdx < 20) {
            title = itemContent.substring(0, splitIdx).trim();
            desc = itemContent.substring(splitIdx).trim();
            // Clean up leading commas or punctuation in description
            if (desc.startsWith('，') || desc.startsWith(',') || desc.startsWith('；') || desc.startsWith(';')) {
              desc = desc.substring(1).trim();
            }
          } else if (itemContent.length > 15) {
            title = itemContent.substring(0, 12).trim() + '...';
          } else {
            title = itemContent;
            desc = '';
          }
          
          items.push({
            id: j,
            title,
            desc
          });
        }
      }
      
      if (items.length === 0) {
        items.push({
          id: 1,
          title: '推荐学习建议',
          desc: content
        });
      }
      
      result.suggestions = items;
      result.suggestionsPrefix = prefix;
    } else {
      result[current.key] = content;
    }
  }

  return result;
}
```
