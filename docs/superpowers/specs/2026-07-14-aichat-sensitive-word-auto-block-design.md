# AI Chat 屏蔽词自动终止与语义复核设计

## 目标

AI Chat 对本地高风险短语先做确定性召回，再复用现有聊天模型进行结构化语义复核。明确危险请求或危险输出命中后立即终止回答，前端只显示“抱歉，我无法回答你的问题”和安全终止提示；教学、防范、新闻等非操作性语境允许继续回答。

## 架构选择

- 选用“本地词表 + 结构化语义复核 + 流式输出门禁”。词表负责低成本召回，语义模型负责降低误杀，流式门禁负责在危险片段进入 EDU SSE 前终止。
- 复用 `build_chat_model_from_settings(stream=False)` 和 AgentScope 2.0.3 `generate_structured_output()`，不新增 SDK、密钥或环境变量。
- 不把审核实现成 Agent 工具。内容安全是横切运行时约束，必须在 Agent 推理和产品 SSE 协议之间执行，不能由模型选择是否调用。
- 不采用假数据。测试使用可注入的确定性审核 client，生产使用真实模型；模型不可用时回退到现有高风险“行为 + 意图”词表。

## 判定规则

结构化审核只返回 `action/category/confidence/reason_code`。以下意图阻断：危险制作或交易步骤、攻击与凭据窃取、侵害或剥削、自伤方法、规避监管或促进违法行为。以下语境放行：风险预防、法律与新闻讨论、非操作性的教学解释、明确反对或求助语境。

只有 `action=block` 且 `confidence >= 0.8` 才采用语义阻断。审核超时、模型未配置或结构化输出失败时，本地词表候选作为高危硬词阻断。审核结果和日志只记录类别、原因码、置信度与命中数量，不记录命中原词或用户正文。

## 数据流

输入命中候选时，在创建 Agent 前完成复核。阻断事件序列为：

```text
workflow_started
content_safety_reviewed(action=block)
text_delta("抱歉，我无法回答你的问题。")
workflow_completed
```

为控制首字延迟，只有输入命中候选时才进行一次语义复核，普通输入不调用审核模型。输出流使用独立滚动窗口做跨分片本地检测，命中后不再等待第二次模型调用，直接关闭 AgentScope async stream 并发送统一事件序列；这会保守拦截极少数主动复述高危短语的安全回答。普通回复在 `workflow_completed` 前发送最终安全审核事件，确保 Backend 在终态持久化前已取得审核元数据。

Backend 收到 `action=block` 时清空此前累计正文和事件时间线，只持久化后续统一拒答文本、安全审核元数据与必要的 run 标识。Frontend 当前流和历史消息都从 `content_safety_review` 恢复 `safetyBlocked`，隐藏任何已有正文并展示自动终止原因。

## 契约与验证

不新增 Client API、Agent HTTP 路径或 SSE 事件类型。`content_safety_reviewed` 继续使用现有字段，本地命中语义由 `flag` 调整为经复核后的 `allow|block`。

测试覆盖危险输入不启动 Agent、正常输入不调用语义模型、教学语境候选放行、跨分片危险输出关闭流、审核超时或不可用时硬词阻断、命中原词不进入 SSE/run store/Backend 持久化、前端当前消息与历史消息一致展示。当前版本以速度优先，不宣称绝对准确；后续可用版本化真实模型判定集持续统计危险样本召回率和正常样本误杀率。
