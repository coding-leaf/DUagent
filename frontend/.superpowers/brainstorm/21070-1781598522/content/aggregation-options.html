聚合错题的几种方案

针对如何将独立的个性化错题一并练习，这里有三种可能的交互方式。

A

按生成批次/来源分组 (推荐)

自动将同一次测试中产生的多道错题打包成一个"练习任务"。保留了错误发生时的上下文。

示例 UI
🎯 随堂测验错题集 (共4题)
包含: React Hooks, 组件生命周期
B

自由勾选组卷（错题本/购物车模式）

列表展示所有独立的错题或错题组，用户像加购物车一样自由勾选，然后点击"一键组卷"开始批量练习。

示例 UI
[知识点A] 题目1
[知识点B] 题目2
C

当前“按知识点”分组升级（允许合并）

在现有卡片基础上，增加“快速组合”功能，可以勾选多个知识点的卡片一起练习。

示例 UI
知识点：React Hooks (3题)
知识点：组件通信 (2题)
