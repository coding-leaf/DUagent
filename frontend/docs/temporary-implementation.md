# Frontend Temporary Implementation

本文档记录当前前端临时实现约束、已知限制和替换条件。长期稳定决策写入 `decisions.md`，当前进度写入 `../WORKFLOW.md`。

## 当前临时约束

- 阶段一只实现现有 Client API 能支撑的主链路。
- 真实联调默认 `VITE_USE_MOCK=false`。
- Mock 仅用于本地演示和断网调试。
- 后端返回空数组或空值时展示 Empty/Unknown。
- 超出 Client API 的页面字段不进入正式开发，先进入阶段二契约审查。

## 已知限制

- 资源详情正文阅读、阅读进度、累计学习时长、建议学习时长尚未完成契约对齐。
- 认知成长曲线、掌握度趋势、路径节点细粒度状态尚未完成契约对齐。
- 班级 AI 洞察、覆盖率、排名、动力指数尚未完成契约对齐。
- 教师端学生深度诊断、资源偏好分布、复杂资源统计、导出报告尚未完成契约对齐。
- 管理员智能体日志、用户管控动作、系统运行状态尚未完成契约对齐。

## 禁止的临时补法

- 在页面组件中硬编码正式字段。
- 用 Mock 数据模拟正式后端缺失字段。
- 前端自行定义未在 Client API 声明的状态枚举。
- 前端直接调用 Agent Service 或推测 Agent API 响应。
- 把页面字段报告中的完整设想直接当作验收标准。

## 替换条件

当阶段二契约审查完成，并明确 Client API、Backend SQL、Backend 聚合逻辑和必要 Agent 数据来源后，本文件中的对应临时限制应被移除或改写。

每次移除临时限制时，需要同步：

- `../WORKFLOW.md` 的当前状态。
- `goals.md` 中的阶段目标，如目标发生变化。
- `decisions.md` 中相关稳定决策，如决策发生变化。
