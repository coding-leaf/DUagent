# 项目遗漏任务与优化列表

经过对 `docs/归档/API_前端接口规范.md`、当前已实现接口（`src/api/services` 和 `src/api/mock`）以及前端源码的全面比对，总结出以下遗漏的接口任务、未翻译的英语文本以及 Mock 数据需要完善的点。

## 一、 遗漏的 API 接口任务

### 1. 认证模块 (`/api/v1/auth`)
- [ ] **1.4 刷新 Token**: 客户端 Token 过期后的续期逻辑。
- [ ] **1.5 发送重置密码验证码**: 忘记密码流程。
- [ ] **1.6 重置密码**: 提交新密码。

### 2. 用户信息 (`/api/v1/users`)
- [ ] **2.2 修改个人信息**: 修改昵称、头像等基本资料。

### 3. 课程管理 (`/api/v1/courses`)
- [ ] **3.2 创建课程 / 开班**: 教师端创建新课程。
- [ ] **3.3 加入课程**: 学生端输入邀请码或通过特定方式加入课程。

### 4. 系统管理 (`/api/v1/admin`) **(整个模块完全缺失)**
- [ ] **5.1 用户列表**: 后台管理员查看所有用户。
- [ ] **5.2 修改用户信息**: 管理员编辑权限/信息。
- [ ] **5.3 移除用户**: 管理员封禁/删除用户。
- [ ] **5.4 Agent 运行日志**: 查看多智能体系统的内部调度日志。
- [ ] **5.5 系统运行日志**: 系统整体运行状态。
> 目前项目中还没有专门的 Admin 后台页面，需要新增路由及配套 UI。

### 5. 学习效果与画像 (`/api/v1/evaluation` & `/api/v1/profile`)
- [ ] **6.2 刷新学习效果评估**: 触发 Agent 重新计算学习效果。
- [ ] **7.1 冷启动引导对话**: 新注册用户首次登录时的对话交互采集。
- [ ] **7.3 刷新用户画像**: 触发 Agent 重新生成画像。

### 6. 其他缺失接口
- [ ] **8.3 节点资源推荐** (学习路径): 根据节点获取外部推荐。
- [ ] **10.2 触发资源生成** (资源库): 触发 Agent 实时生成课件/练习题。
- [ ] **十二、查询异步任务状态** (`/api/v1/tasks`): 轮询上述“触发生成”类型操作的进度。
- [ ] **十三、Webhook 回调**: (通常是后端侧逻辑，但前端可能需要支持 SSE 或 WebSocket 实时接收)。

## 二、 需汉化/翻译的英文文本

在快速迭代中，项目中残留了部分为了展示“科技感”或 UI 占位用的英文字符，需要进行汉化：

1. **登录/注册页 (`Login.jsx`, `Register.jsx`, `Success.jsx`)**
   - `System Status` -> `系统状态`
   - `ORCHESTRATOR` -> `核心调度器` (或其他符合设定的词)
   - `All agents online` -> `所有智能体在线`
   - `Connection secure` -> `安全连接已建立`

2. **学生画像与报告页 (`StudentProfile.jsx`, `TeacherStudentReport.jsx`, `LearningEffects.jsx`)**
   - 图表周历标签: `MON`, `TUE`, `WED`, `THU`, `FRI`, `SAT`, `SUN` -> `周一` ~ `周日`
   - 分析报告标记: `LIVE FEED` -> `实时分析` 或 `动态流`

3. **全局导航与 UI 杂项**
   - `AIChat.jsx` 顶部的系统名称: `DS_MASTERY_AI` -> `数据结构智能助手` (或其他官方中文名)
   - 检查各个输入框的 `placeholder` 是否有遗漏的英文。

## 三、 Mock 数据补充与完善计划

当前的 Mock 数据 (`src/api/mock/`) 虽然支撑了页面运转，但数量单薄，无法体现大数据量下的 UI 表现（如滚动、分页、极值等）：

1. **`teachingMock.js` (教师端数据)**
   - **问题**: `getClasses` 返回了 4 个班级，但 `getClassStudents` 的 Mock 逻辑写死了固定返回 3 名学生，无法体现出不同班级的差异。
   - **优化任务**: 扩充至 15~30 名学生，并针对不同 `courseId` 返回不同名单。增加低分和高分的极端数据，以测试进度条的边界表现。

2. **`learningMock.js` (路径与资源库)**
   - **问题**: 仅有一套 `CS101` 的固定路径树，资源库列表也是固定的几个资源。
   - **优化任务**: 增加复杂的路径分支（体现前置/后置节点的复杂依赖关系）；给资源列表添加分页 Mock 数据，丰富资源类型（如视频、互动文档混排）。

3. **`quizMock.js` (练习模块)**
   - **问题**: `getQuestions` 只有 3 道题目，且题型较少。
   - **优化任务**: 增加至 10 题以上，包含单选、多选甚至填空题型的 Mock；补充历史练习记录的返回数据，以便测试列表渲染。

4. **`chatMock.js` (AI 答疑)**
   - **优化任务**: 补充更长篇幅的对话历史，测试对话框的滚动行为；增加更多的 `has_visual` 数据，测试不同知识点（如红黑树、图论）的内嵌 UI。
